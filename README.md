# 视频下载工具 v5.0

一个功能强大的视频下载工具，支持B站、抖音、YouTube等主流视频平台的视频下载。

## ✨ 功能特点

### 🎯 核心功能
  多平台支持: 支持B站、抖音、YouTube、腾讯视频、爱奇艺、优酷等1000+网站
  平台特定优化: 针对各个平台的特殊处理，提供最佳下载体验
  批量下载: 支持同时下载多个视频，提高效率
  断点续传: 网络中断后可继续下载未完成的任务

### 🖥️ 用户界面
  图形界面: 简洁美观的GUI界面，操作简单直观
  主题切换: 支持浅色/深色主题，保护眼睛
  实时进度: 显示下载进度、速度和剩余时间
  详细日志: 提供详细的操作日志和错误信息

### 🎬 下载功能
  质量选择: 支持多种视频质量选择（最佳质量、1080p、720p、480p等）
  格式转换: 支持MP4、AVI、MKV、WebM等格式转换
  字幕支持: 自动下载中英文字幕（如果有）
  信息预览: 下载前可查看视频详细信息

### 🔒 安全特性
  隐私保护: 下载历史记录加密存储，保护用户隐私
  本地存储: 所有配置和数据本地保存，不上传云端
  安全加密: 使用AES-256加密算法保护用户数据

### 📁 便捷功能
  自定义路径: 支持自定义下载保存路径
  一键粘贴: 支持一键粘贴视频链接
  完成通知: 下载完成后自动提醒
  自动安装: 支持自动安装FFmpeg等依赖工具

## 🚀 快速开始

### 方法一：直接运行（需要Python环境）

1. 安装Python
   下载Python 3.7或更高版本：https://www.python.org/downloads/
   安装时请勾选"Add Python to PATH"

2. 安装依赖
   双击运行 安装依赖.bat
   或手动安装 pip install -r requirements.txt

3. 启动程序
   双击运行 启动程序.bat
   或直接运行 python main.py

### 方法二：便携版（无需Python环境）

1. 打包程序
   python 打包程序.py

2. 使用便携版
   双击启动工具.bat或直接运行视频下载工具.exe

## 📖 使用说明

### 基本使用流程

1. 获取视频链接
   在视频平台复制视频分享链接
   或复制浏览器地址栏中的视频URL

2. 粘贴链接
   在URL输入框粘贴视频链接
   支持单条和批量模式切换

3. 设置参数
   选择视频平台（可选，默认自动检测）
   选择视频质量和格式
   设置下载路径

4. 开始下载
   点击"获取信息"查看视频详情（可选）
   点击"开始下载"按钮
   等待下载完成

### 高级功能

  批量下载: 勾选"批量下载模式"，输入多个URL（每行一个）
  断点续传: 勾选"启用断点续传"，网络中断后可继续下载
  格式转换: 勾选"下载后转换格式"，选择目标格式
  主题切换: 点击"切换主题"按钮，选择喜欢的主题

## 🔧 常见问题

### Q: 程序启动时提示"未找到Python"
A: 请先安装Python 3.7+，确保安装时勾选"Add Python to PATH"

### Q: 下载失败怎么办？
A: 
  检查网络连接
  确认视频链接是否正确
  尝试更新yt-dlp：pip install --upgrade yt-dlp
  某些平台可能需要登录才能下载
  查看日志窗口获取详细错误信息

### Q: 下载速度很慢？
A: 
  下载速度取决于视频平台服务器和网络状况
  可以尝试更换网络环境
  避免高峰时段下载

### Q: 无法下载某个平台的视频？
A: 
  视频平台可能更新了反爬虫策略
  尝试更新yt-dlp到最新版本
  某些付费内容可能无法下载
  抖音视频链接格式可能需要特殊处理

### Q: 下载的视频没有声音？
A: 
  程序会自动合并音视频
  如果出现问题，请确保已安装FFmpeg
  点击"安装FFmpeg"按钮自动安装
